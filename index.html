Conceptos fundamentales del Diplomado IA

1. Agente

Programa autónomo que percibe entorno, decide acciones y ejecuta tareas.

2. Multiagente

Sistema compuesto por varios agentes que colaboran resolviendo problemas complejos.

3. Uso de Multiagente

Permite coordinar agentes especializados para resolver tareas eficientemente.

4. Droid

Software automatizado diseñado para asistir funciones específicas eficientemente.

5. Fake Bot

Bot simulado que imita comportamientos humanos para pruebas controladas.

6. Repositorio

Almacena, organiza versiones, comparte código y documentación colaborativamente.

7. GitHub

Plataforma colaborativa para alojar y compartir proyectos de software.

8. Funcionamiento GitHub

Utiliza repositorios Git para cambios, colaboración y seguimiento.

9. Claude vs Droid

Claude genera contenido inteligente; Droid automatiza tareas específicas.

10. Open Cloud

Plataforma abierta para gestionar servicios, recursos y datos en nube.

11. Sesión en Ollama

Interacción temporal donde el modelo responde consultas continuamente.

12. Sistema Predictivo

Agentes analizan datos y anticipan eventos futuros mediante patrones.

13. Capacitación con Agentes

Permite entrenar personas mediante simulaciones y retroalimentación inmediata.

14. Skill

Capacidad específica que permite ejecutar tareas o funciones determinadas.
